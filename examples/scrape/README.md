# scrape-example

A standalone example crate for
[prometheus-scrape-parser-rs](https://github.com/angrybird3306/prometheus-scrape-parser-rs):
it scrapes one Prometheus text exposition endpoint with
[reqwest](https://docs.rs/reqwest) and parses the whole body with the
unified [`Parser`](https://docs.rs/not-published-yet), printing
every metric family it yields.

## Usage

Run from this directory (no build system wiring to the parent crate — this is its own crate):

```bash
cargo run -- http://localhost:9090/metrics
```

The URL argument is optional; it defaults to `http://localhost:9090/metrics`.

## Sample output

Against a live Prometheus `/metrics` endpoint:

```
go_gc_cycles_automatic_gc_cycles_total (Counter)
  # Count of completed GC cycles generated by the Go runtime. Sourced from /gc/cycles/automatic:gc-cycles.
  value: Sample(17.0)
go_gc_duration_seconds (Summary)
  # A summary of the wall-time pause (stop-the-world) duration in garbage collection cycles.
  value: Summary(SummaryValue { sample_count: Some(17), sample_sum: Some(0.000578432), quantiles: [...] })
```

The final line is the parser's `Stats` — lines processed, metrics
parsed, and anything skipped:

```
Stats { lines_total: 1156, metrics_total: 356, skipped_lines: 0, skipped_metrics: 0, skipped_families: 0, pruned_families: 0, last_error: None }
```

## Notes

- This crate carries its own `.cargo/config.toml` with the `buf` registry
  entry (`sparse+https://buf.build/gen/cargo/public/`); the parent library
  depends on a `buf`-hosted protobuf crate, and without that entry cargo
  cannot resolve the path dependency.
